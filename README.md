# 🧠 EJERCICIO | RED NEURONAL BÁSICA | ING. EN VIDEOJUEGOS

¡Bienvenidos al ejercicio de **Red Neuronal Básica desarrollado con Brain.js**!

Este proyecto fue desarrollado con fines educativos para estudiantes de **Ingeniería en Videojuegos**, como parte de la materia **Inteligencia Artificial Aplicada en Videojuegos**.

A través de este ejercicio podrás explorar cómo funciona una red neuronal básica mediante una interfaz web interactiva. Al seleccionar diferentes colores de fondo, la red neuronal procesa sus componentes RGB y determina si el texto debe mostrarse en blanco o negro, según el resultado de su predicción.

## 🎯 Objetivo del proyecto

Explorar los fundamentos de las redes neuronales y su aplicación en interfaces interactivas, utilizando un modelo entrenado para seleccionar el color del texto en función del color de fondo.

## 🛠️ Tecnologías utilizadas

- **Lenguaje de programación:** JavaScript
- **Biblioteca de inteligencia artificial:** Brain.js
- **Selector de color:** jscolor
- **Tecnologías web:** HTML, CSS y JavaScript
- **Tipo de proyecto:** Ejercicio práctico de inteligencia artificial aplicada a interfaces web

## 📂 Archivos del proyecto

### Código fuente

En este repositorio encontrarás el código fuente necesario para ejecutar el ejercicio y estudiar su funcionamiento.

Puedes revisar cómo se entrena la red neuronal con ejemplos de colores, cómo se procesan los componentes RGB del color seleccionado y cómo se utiliza la predicción obtenida para modificar el color del texto en la interfaz.

## 🎓 Uso educativo

Este proyecto está destinado a fines educativos y forma parte del material de apoyo de la materia **Inteligencia Artificial Aplicada en Videojuegos**.

Puedes utilizarlo como referencia para estudiar los fundamentos de las redes neuronales, comprender el proceso de entrenamiento mediante ejemplos y explorar cómo un modelo de inteligencia artificial puede integrarse en una aplicación interactiva.
